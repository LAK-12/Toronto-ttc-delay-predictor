# Toronto TTC Delay Predictor 

I use the TTC pretty often, and one thing I kept noticing was how inconsistent travel time could be. The same route might take around 20 minutes one day and 40 minutes another because of delays, service issues, or unexpected disruptions.

That made me curious about whether historical TTC data could help explain some of those patterns and whether machine learning could be used to estimate how long a delay might last once an incident happens.

## Goals

The main goals of this project are to:

- clean and analyze historical TTC delay data
- identify patterns across routes, times, days, and incident types
- use SQL to explore and summarize delay trends
- build and evaluate a machine learning model for delay duration
- create clear visualizations and dashboards to communicate findings

## What I want to explore

- Which TTC routes experience the most delays?
- What times of day tend to have longer delays?
- Are certain days of the week more delay-prone?
- Which incident types cause the longest disruptions?
- Can historical delay patterns help predict the duration of a new incident?
